# DKT Practice

A practice quiz for the NSW Driver Knowledge Test — 353 questions across 10 topics, with the
official diagrams and explanations. Open `index.html`, no build step or server required.

Study aid only, not an official test — check the current
[Road Users' Handbook](https://www.nsw.gov.au/driving-boating-and-transport) for the rules that
actually apply.
